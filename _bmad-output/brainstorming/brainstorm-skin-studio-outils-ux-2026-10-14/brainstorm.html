Technique 03

SCAMPER

Sept tuiles sur la console de calibration — clique une lettre pour ouvrir son jeu de mutations.

Substitute (substituer)

  • Saisie hex → picker contraint qui ne commit que des ids de palette
  • Édition seulement à droite → double chemin : clic maquette ou liste filtrée par type
  • Un seul aperçu → fantôme du second skin en split d’opacité (pas un vrai film overlay)

Combine (combiner)

  • Swatch + badge where-used + clic pour surligner sur la maquette
  • Switcher skin + barre d’états + puce type d’objet dans une seule bande contexte
  • Dupliquer un skin + assistant remap d’accents pour Duo / Monochrome

Adapt (adapter)

  • UI modes variables Figma pour cinq skins — sans nouvelle métaphore
  • Replace colour Photoshop pour rebind d’entrée palette dans un skin
  • Contrôles Storybook pour la machine d’états du type sélectionné

Magnify / Modify (amplifier)

  • Loupe / mode focus sur le contrôle sélectionné sans perdre la maquette
  • Mappings non liés en checklist rouge/ambre qui domine la sidebar jusqu’à zéro
  • Grouper les micro-glissements picker en une seule étape d’historique

Put to other uses (autres usages)

  • Export JSON aussi comme diff de contrat en lecture seule entre deux skins
  • Bootstrap Collect comme outil de re-merge plus tard — pas un import one-shot seulement
  • Préférence UI Scale en raccourci clavier partagé avec le plugin

Eliminate (éliminer)

  • Hex libre sur le chemin mapping — hex seulement en éditant une entrée palette
  • Overrides par instance — mappings au niveau type uniquement
  • Panneaux bas jusqu’à la V2 — chrome = canvas + une sidebar + fine top bar

Reverse (inverser)

  • Partir de la liste des tokens non mappés → saut sur la maquette → puis mapper
  • Éditer la palette globale et voir tous les skins se rafraîchir (avec prudence)
  • Mode paint-bucket : choisir d’abord l’entrée palette, puis l’appliquer aux propriétés

Climax · Synthèse

Le Studio gagne par la vitesse de calibration — pas en devenant Figma

Voler sélection, modes et usage des swatches. Rejeter l’envie de layout. Les contrats d’interaction (contexte collant, mappings = ids palette) sont des exigences PRD dures — pas du « nice UX ».

Flash where-used → Checklist non mappé → Paint-bucket ↻ Palette nommée

Retenir

  • Mappings = ids palette seulement
  • Contexte collant skin / type / état / vue
  • Switcher modes skins en haut
  • Signal compteur non mappé
  • Undo coalescé
  • Sync canvas ↔ sidebar
  • Chrome : canvas + sidebar droite + fine top bar

Explorer (bientôt / V2)

  • Where-used + refactor rename
  • Compare skins côte à côte
  • Replace-colour / paint-bucket
  • Recherche + zoom-to-selection
  • Brouillon vs prêt-pour-plugin
  • Indices contraste · merge import
  • Arbre layers · inspect JSON · historique

Rejeter

  • Auto Layout / vecteurs / effets
  • Vrais overlays / adjustment layers
  • Hex libre sur le chemin mapping
  • Second produit Matrix-Control
  • Chrome bas dès le MVP
  • Éditeur typo complet dès le MVP

Forme MVP

  • A1 + B1 + C1 + D1 + F2
  • Les mappings ne commitent que des ids palette
  • Changer de skin conserve pan, zoom, sélection, état
  • Compteur non mappé visible avant de prétendre exporter
  • Pas d’arbre layers gauche, pas de panneaux bas

Paquet plus tard

  • E2 côte à côte + flash where-used
  • Replace-colour pour balayer Duo / Monochrome
  • Rail palette gauche optionnel (job couleur vs binding)
  • Recherche / zoom ; verrou brouillon ; contraste ; merge import
  • Park grille D3 / historique A3 sauf si Collect explose
Note PRD : spécifier le contexte collant et les mappings = ids palette comme contrats d’interaction durs. Trois chapeaux, une boucle — flash where-used, checklist non mappé et paint-bucket — tournent tous autour de la palette nommée.
