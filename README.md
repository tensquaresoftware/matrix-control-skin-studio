# Matrix Control Skin Studio

Web editor for Matrix-Control plugin skins.

## Requirements

- Node.js `^20.19.0 || >=22.12.0`
- npm (lockfile committed for reproducible installs)

## Setup

```bash
npm install
```

## Scripts

```bash
npm run dev      # start Vite dev server
npm run build    # typecheck + production build into dist/
npm run preview  # serve the production build locally
npm test         # scaffold matrix checks (Node test runner)
```

Open the URL printed by `npm run dev` in a desktop browser. The boot surface shows **Skin Studio**.
